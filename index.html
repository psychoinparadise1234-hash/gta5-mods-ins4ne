How to Add Your Mods

Step-by-step guide for adding new mods to this portfolio

1

Edit index.html

Open the index.html file in any text editor (Notepad, VS Code, etc.)

Find the section that says <!-- Mod Card X -->

2

Copy a Mod Card

Copy this entire mod card block:

<div class="mod-card">
    <div class="mod-icon">🚗</div>
    <h3>Your Mod Name</h3>
    <p>Description of your mod</p>
    <div class="mod-type">Physics Tasks</div>
</div>
3

Customize Your Mod

Replace the emoji: Pick any emoji that fits your mod

Change the name: Use something descriptive like "Custom Handling v2"

Add description: Keep it short and clear (1-2 sentences)

Set the type: Choose either "Physics Tasks" or "Vehicle Edit"

4

Paste Into mods-grid

Find the <div class="mods-grid"> section

Paste your new mod card before the closing </div>

Example:

<div class="mods-grid">
    <!-- existing mod cards -->
    <!-- YOUR NEW MOD CARD GOES HERE -->
</div>
5

Save & Check

Save the index.html file

Open it in your browser to preview

Your new mod should appear in the gallery!

6

Upload to GitHub

Go to your GitHub repository

Click the index.html file

Click the edit button (pencil icon)

Paste your updated content

Scroll down and click "Commit changes"

Your live site updates in seconds!

💡 Pro Tips

  • Emoji Ideas: 🚗 🏎️ ⚙️ 🛞 💨 ⚡ 🔧 🎯
  • Good Names: "Custom Handling v1", "Drift Physics v2", "Lightweight Pack"
  • Type: "Physics Tasks" = physics.ymt edits, "Vehicle Edit" = vehicle handling changes
  • Keep Descriptions Short: 1-2 sentences max
  • Don't Copy: Never copy entire HTML - just the mod card div

⚠️ Common Mistakes

  • Forgetting to close the </div> tag
  • Copying more than just the mod card
  • Removing existing mod cards by accident
  • Typos in HTML tags (watch brackets and spelling)
